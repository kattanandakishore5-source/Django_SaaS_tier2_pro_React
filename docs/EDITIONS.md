# Editions Comparison

This boilerplate is the **Tier 2 Pro Edition**.

## Tier 1: Core (Base)
- Basic Django Backend
- Django Templates / HTMX
- Basic Session Auth
- No background workers
- Basic SQLite setup

## Tier 2: Pro (This Repository)
- **React/Vite SPA Frontend** with Tailwind & shadcn/ui.
- **Strict TypeScript API integration**.
- **Celery & Redis** for background task processing.
- **Server-Authoritative Entitlements** (Database-level locks and feature gating).
- **Stripe Subscriptions** with secure webhook synchronization.
- **Dockerized** production-ready infrastructure.
- **CI/CD** pipelines ready for GitHub Actions.
